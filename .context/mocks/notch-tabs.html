Notch rework: tabs, pinned connectors, settings

Whisper Master quick-actions band. Today it shows one fixed view (Today + Recent notes + three buttons). The ask: a Notes tab, a Connectors tab that shows the connectors you pin in the app, and a Settings tab. Three layouts below. They are mocks only. No Swift was changed. Pick one (or mix parts) and I build it.

What to take: tabs top-left, tools top-right (everyone converges on this); a tab appears only when it has something (Atoll), which fits "a pinned connector adds a tab"; one sliding selection capsule. GPL code (boring.notch, Atoll) is reference only, not copied. NotchNook / Alcove are closed source and were not inspected.

Rules all three variants keep

  • Opens on hover dwell, as today (NotchHoverGesture). Tab change is a click. Hover over a tab does not switch it (the pointer crosses tabs on the way down).
  • No text fields in the band. It is a non-activating panel. Anything that needs typing still opens the window (New note, New reminder, Connect).
  • Pin is per connection, not per kind: "Gmail - Work" and "Gmail - Personal" pin apart. Max 3 pins. Pinning happens in the app (Connectors page), unpin also works from the band.
  • Connector rows are read-only. Click a row opens the item (mail, Slack thread, event) in its own app or browser.
  • The band opens on the tab you used last. A blocked or error connection shows its error line, never an empty list.
  • Settings tab holds only quick switches that take effect at once. Full Settings stays one click away.

ATab strip in the header (boring.notch style)

One header row: tabs at the left, gear at the right. Gear is the Settings tab. The Connectors tab shows each pinned connection as a column. Familiar, low risk, closest to today's code (the header row already exists).

Recommendation

C if the connectors are the reason to open the band: it puts each pinned app one click away and shows its count before you click. A if you want the smallest change to today's code and a stable tab bar. B costs the most width and adds a second click per connector, so I would not pick it.

Open points

  • Calendar connections already feed the Today tab. Should a pinned calendar also get its own tab (shown in the mocks), or should calendars be pin-free and only mail/Slack get pins?
  • Counts need a live read. Plan: refresh pinned connectors when the band opens and every 5 min while the app runs, never on each hover tick.
  • Settings tab switches: the six shown are a proposal. Tell me which ones you want there.
